# postman-viewer

> 📦 Postman `.postman_collection.json` dosyalarını okunabilir ve sade bir `postmanView` formatına dönüştüren analiz paketi.

## ✨ Özellikler

- Postman koleksiyonlarını analiz eder
- Klasör yapısı içindeki tüm request'leri çözümler
- JSON çıktısı sadeleştirilmiş `PostmanView` formatındadır
- Next.js / React.js projeleriyle uyumludur

## 🚀 Kurulum

```bash
npm install postman-viewer
```
